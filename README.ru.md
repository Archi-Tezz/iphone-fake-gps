# iphone-fake-gps

**Подмена геопозиции на iPhone с компьютера — по кабелю, с картой.**

Поставить айфону любое местоположение или «провезти» его по маршруту: пешком,
на машине, поездом или самолётом. Работает на штатном механизме Apple —
без джейлбрейка, патчей и профилей конфигурации.

<sub>Программа и её команда называются `ios-loc`. · [English version](README.md)</sub>

![панель управления](docs/screenshots/panel-dark.jpg)

</div>

## Что это

Фейк GPS для айфона, управляемый из Windows. Эмуляция местоположения идёт тем же
механизмом, что и **Simulate Location** в Xcode
(`com.apple.instruments.server.services.LocationSimulation`), через usbmuxd —
транспорт, которым уже пользуются Finder и iTunes.

* **Клик по карте** — переместить устройство туда. Никаких режимов.
* **Shift + клик** — построить маршрут; точку можно тянуть мышью, клик по ней удаляет.
* **Профили движения** — на месте, пешком, бег, велосипед, авто по городу,
  трасса, поезд, самолёт. У каждого своя крейсерская скорость, разгон,
  дрожание GPS и скорость разворотов.
* **Маршруты** рисуются мышью, прокладываются по дорогам, импортируются из GPX,
  выгружаются в GPX и сохраняются под именем.
* **Ручное управление** клавишами W A S D или стрелками, с плавными поворотами.
* **Пять видов карты** на двух движках — растровые работают везде, векторные там,
  где есть WebGL.
* **Русский и английский** интерфейс, светлая и тёмная темы.
* **Работает без кабеля** по Wi-Fi, а саму панель можно открыть **на телефоне**.

## Что нужно

| | |
|---|---|
| **Windows 10/11** | проверено на Windows 10 Pro 19045 |
| **Apple Mobile Device Support** | **обязательно** — установите Apple Devices из Microsoft Store или iTunes с сайта Apple |
| **iPhone с iOS 13+** | iOS 17 и новее подключаются через RemoteXPC-туннель, он поднимается сам |
| **Python 3.9+** | только для запуска из исходников; готовой сборке ничего не нужно |

Windows сама по себе не умеет общаться с айфоном — драйвер Apple и создаёт
USB-транспорт. Всё остальное программа несёт с собой.

### iOS 16 и новее: Режим разработчика

На iPhone: **Настройки → Конфиденциальность и безопасность → Режим разработчика**
→ включить. Устройство перезагрузится и попросит подтвердить.

**На новом телефоне этого пункта нет, и это нормально** — iOS прячет его, пока
с телефоном не поговорит инструмент разработки. Нажмите **«Не вижу Developer
Mode»** в списке устройств или выполните `ios-loc.exe devmode`, и пункт появится.

## Установка

Скачайте архив из [Releases](../../releases), распакуйте куда угодно и запустите
`ios-loc.exe`. Python не нужен.

Windows покажет предупреждение SmartScreen о неподписанной программе —
сертификат для подписи стоит денег. **Подробнее → Выполнить в любом случае.**

<details>
<summary>Запуск из исходников</summary>

```bash
git clone https://github.com/Archi-Tezz/iphone-fake-gps.git
cd iphone-fake-gps
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m iosloc ui
```

Если установка падает на сборке `lzfse`: это C-расширение без готовых колёс,
которое тянется транзитивно через `ipsw_parser` и нужно только для прошивок —
их проект не трогает. Либо поставьте MSVC Build Tools, либо заглушку:

```bash
.venv\Scripts\python.exe -m pip install tools\lzfse-stub
```

</details>

## Как пользоваться

Запустите `ios-loc.exe`, нажмите **Подключить**, выберите устройство. Дальше —
клик по карте.

| Действие | Как |
|---|---|
| Переместить устройство | клик по карте или перетащить синий маркер |
| Добавить точку маршрута | **Shift + клик** |
| Исправить точку | потянуть мышью; клик по ней — удалить |
| Меню действий | **правый клик** — переместиться, добавить в маршрут, сохранить точку, скопировать координаты |
| Поехать по маршруту | **Начать движение** |
| Сменить профиль | клик по нему или клавиши **1**–**8** |
| Пауза | **пробел** |
| Ручное управление | **W A S D** / стрелки, **Shift** — ускорение |

Камера следует за устройством, но стоит потянуть карту рукой — слежение
отключается, и появляется кнопка **«К устройству»**, чтобы вернуться.

![меню на карте](docs/screenshots/context-menu.jpg)

### Путешествия: доехать, долететь, дойти

Введите, куда хотите попасть — город, код аэропорта или координаты — и маршрут
разложится на этапы, у каждого свой профиль движения:

```
Доехать до VKO    Авто, город     21.8 км
Перелёт VKO → DXB Самолёт       3680.7 км
Доехать от DXB    Авто, город     11.3 км
```

Ближайший аэропорт к каждому концу берётся из встроенной базы: **1150
аэропортов в 217 странах**, собранной из [OurAirports](https://ourairports.com/)
(общественное достояние, обновляется ежедневно). Поиск аэропортов работает без
интернета.

Короткие поездки остаются наземными: перелёт закладывается, только если он и
правда составляет основную часть пути — в соседний город вас через аэропорт не
повезут. Этапы сменяются сами: закончилась дорога — включается профиль самолёта
со своим разгоном, прямо посреди маршрута.

Обновить базу аэропортов: `tools/make_airports.py`.

### Готовые маршруты

За кнопкой **«Готовые маршруты»** в блоке путешествия — список подготовленных
поездок: Москва → Франкфурт, Москва → Дубай → Токио, Париж → Рим → Барселона →
Амстердам и другие. Нажали — маршрут построился от текущего места устройства,
каждый этап поедет, полетит или пойдёт со своим профилем.

Свои добавляются туда же: впишите коды аэропортов через пробел — `SVO DXB NRT` —
и нажмите «Добавить». Коды проверяются по базе до сохранения, так что
сохранённый маршрут всегда рабочий. Они остаются после перезапуска.

Старт далеко от первого аэропорта обрабатывается разумно: из Владивостока
маршрут Москва → Дубай превратится в «доехать до VVO → перелёт VVO → SVO →
перелёт SVO → DXB», а не в поездку на машине через полстраны. Между соседними
аэропортами программа поедет, а не полетит.

### Проверка, что подмена работает

Панель знает только то, что она отправляет; чему верит iPhone — видно только на
iPhone. Иконка с галочкой справа сверху сводит обе половины на один экран:
устройство, канал, включена ли подмена, сколько координат телефон принял и
сколько секунд назад была последняя — один счётчик не отличает живой поток от
замершего — и точные координаты, которые надо увидеть. Ниже три шага, чтобы
убедиться на телефоне: «Карты», стрелка геопозиции, синяя точка.

### Видно, что программа работает

Запущенная двойным кликом, такая программа — это консольное окно, которое
печатает строчку и замолкает на часы; отличить его от окна, которое вот-вот
закроется, невозможно. Поэтому оно само говорит, что это: окно подписано в
заголовке и начинается с таблички, где адрес панели, порт, номер процесса и
путь к журналу, а дальше в него построчно идёт всё, что происходит, —
подключения, этапы маршрута, обрывы связи.

Тот же журнал есть в панели, за иконкой листка справа сверху, — это удобно,
когда панель на телефоне, а окно на компьютере в другой комнате. Он следит за
концом файла, подсвечивает предупреждения и ошибки и краснеет сразу, как
программа перестаёт отвечать.

Рядом с программой лежат три запускалки:

| Файл | Что делает |
|---|---|
| `start.cmd` | Запускает панель и не даёт окну закрыться, даже при падении |
| `log.cmd` | Показывает журнал и следит за новыми строками |
| `start-lan.cmd` | Запускает сразу с доступом с телефона и QR-кодом |

Из командной строки: `ios-loc.exe log -f` — следить за журналом,
`ios-loc.exe log -n 500` — последние 500 строк.

### Карты

Пять видов на двух движках, выбираются в настройках:

| Вид | Движок | Нужен WebGL | Источник |
|---|---|---|---|
| Стандартная | Leaflet (растр) | нет | OpenStreetMap |
| Спутник | Leaflet (растр) | нет | Esri World Imagery |
| Топографическая | Leaflet (растр) | нет | OpenTopoMap |
| Векторная / светлая | MapLibre | **да** | OpenFreeMap |
| Векторная тёмная | MapLibre | **да** | VersaTiles |

Режим **Авто** берёт векторную там, где доступен WebGL, и растровую там, где нет.
Если векторная карта не отрисовалась за десять секунд, программа сама
переключается на стандартную и говорит об этом, вместо чёрного прямоугольника.
Ни один источник не требует API-ключей.

![спутник](docs/screenshots/panel-satellite.jpg)

### Настройки

![настройки](docs/screenshots/settings.jpg)

Язык интерфейса, тема, вид карты, единицы скорости, слежение камерой,
пройденный путь, управление с клавиатуры, наклон и поворот, онлайн-сервисы.
Всё сохраняется между запусками.

**Онлайн-сервисы выключены по умолчанию.** Поиск адресов (Nominatim) и маршруты
по дорогам (OSRM) отправляют запросы на публичные серверы OpenStreetMap; пока
переключатель выключен, координаты никуда не уходят. Тайлы карты — отдельная
история: их браузер грузит напрямую, и без интернета карта просто пустая, а всё
остальное работает.

### Без кабеля, по Wi-Fi

Подключите iPhone проводом и один раз выполните:

```bash
ios-loc.exe wifi
```

Это включает wireless lockdown — ту же возможность, на которой работает
синхронизация по Wi-Fi. После этого кабель можно вынуть: пока телефон и
компьютер в одной сети, устройство видно с пометкой `Network` и всё работает
как раньше. Выключить обратно — `ios-loc.exe wifi --off`.

По проводу надёжнее: Wi-Fi медленнее и рвётся, когда телефон засыпает, поэтому
длинный маршрут лучше проходить с кабелем.

### Управление с телефона

```bash
ios-loc.exe ui --lan
```

Программа напечатает адрес, код доступа и QR-код; тот же QR есть в панели, за
иконкой телефона. Отсканируйте — панель откроется в браузере телефона.

![доступ с телефона](docs/screenshots/phone-access.jpg)

**Поставить на телефон.** Когда панель открыта в браузере телефона, нажмите
«Поделиться» → **«На экран «Домой»»**. Дальше она запускается с иконки, на весь
экран, без адресной строки — от приложения почти не отличить. Вёрстка под
телефон: шапка сжимается в одну строку, показания становятся узкой полоской, а
управление живёт в панели поверх карты.

**О безопасности.** Обычный запуск слушает только `127.0.0.1`. Ключ `--lan`
открывает панель всей сети — а панель управляет геопозицией телефона — поэтому
в этом режиме **каждый запрос требует кода доступа**. Код случайный, новый при
каждом запуске и живёт, только пока работает программа; без него сервер отвечает
401 на всё, включая смену координат. В чужой или публичной сети этот режим
включать не стоит.

## Чего программа не делает

* **Шаги и Health не затрагиваются.** Счётчик шагов приходит с motion-сопроцессора
  через `CMPedometer`, а не из CoreLocation, и сервиса симуляции движения Apple
  не предоставляет. Записать что-либо в HealthKit по кабелю тоже нельзя — это
  умеет только приложение на самом устройстве, с разрешения пользователя. А вот
  всё, что считает **дистанцию по GPS** (беговые и велотрекеры, тренировки
  «Бег на улице» и «Велосипед»), работает.
* **Меняются только координаты.** Высота, точность, скорость и курс вычисляются
  самой iOS из последовательности координат. Именно поэтому в профилях движения
  реалистичные скорости.
* **Приложения видят подмену.** iOS помечает симулированные координаты, и
  приложения могут это проверить. В играх и геосервисах за это обычно
  блокируют аккаунт.
* **Экстренные вызовы** определяют положение другими способами и подменой не
  затрагиваются.
* **Подмена живёт, пока запущена программа.** Закрыли окно, выдернули кабель или
  перезагрузили телефон — вернулась настоящая геопозиция. Так устроен механизм
  Apple, поэтому окно должно оставаться открытым — его можно свернуть в трей.

## Если не работает

Начните отсюда — проверяются драйвер, устройство, Режим разработчика и
целостность самой программы:

```bash
ios-loc.exe doctor
```

Всё происходящее пишется в **`ios-loc.log`** рядом с программой — именно этот
файл стоит присылать, если что-то сломалось: окно консоли к тому моменту обычно
уже закрыто.

| Симптом | Что делать |
|---|---|
| `usbmuxd: UNAVAILABLE` | Поставить Apple Devices или iTunes; проверить службу Apple Mobile Device Service в `services.msc` |
| Нет запроса «Доверять этому компьютеру?» | Разблокировать iPhone, переподключить кабель, попробовать другой порт или кабель |
| Нет пункта «Режим разработчика» | Нажать «Не вижу Developer Mode» или выполнить `ios-loc.exe devmode` |
| `Could not mount the Developer Disk Image` | Разблокировать телефон, не вынимать кабель; образ скачивается с серверов Apple, нужен интернет |
| Не поднимается туннель на iOS 17+ | `pip install -U pymobiledevice3` и пересобрать, либо запустить `pymobiledevice3 remote tunneld` от администратора |
| Карта не рисуется | Выбрать **Стандартную** в настройках — векторным нужен WebGL |
| В каком-то приложении позиция не обновилась | Закрыть и открыть его заново: многие кешируют последнюю известную точку |
| Работало, потом перестало двигать устройство | Исправлено в 1.5.0 — простаивающий канал DTX теперь переоткрывается сам. Подробности — в `ios-loc.log` рядом с программой |

## Как это устроено

Путь до устройства отличается по версиям iOS, и `device.py` это скрывает:

* **iOS 13–16** — сервисы разработчика доступны напрямую через lockdown.
* **iOS 17+** — они переехали за RemoteXPC, нужен туннель. Используется
  userspace-туннель на чистом Python (PyTCP) — без прав администратора и без
  TUN-драйвера; запасной вариант — `tunneld`.

Движение считается на сервере: раз в интервал профиля движок делает шаг,
получает координату и отправляет её на устройство. Браузер только опрашивает
состояние и плавно двигает маркер между двумя соседними фиксами — поэтому
картинка выглядит непрерывной, хотя фиксы идут раз в секунду.

Полное описание архитектуры, тестов и сборки — в [английской версии](README.md).
